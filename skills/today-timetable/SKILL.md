# 今日の時間割を始める（朝に 1 回）

朝、**新しいセッション**で「今日の時間割」と打たれたら使う。**このセッションが、そのまま 1 日の時間割のセッションになる。**

前提: Claude のデスクトップアプリの Code タブ。サブセッション（1 つのセッションから立てる、サイドバーに入れ子で並ぶ別のセッション）を使う。下に出てくる `mcp__ccd_...` の道具が読み込まれていなければ、ToolSearch の `select:` で読んでから使う。

## 自分に合わせる所（入れるときに埋める）

- **読む場所:** `<例: 仕事のチャット（Slack の自分宛てと自分の発言）・カレンダー・GitHub の自分の PR と自分宛てのレビュー>`
- **始業と終業の時刻:** `<例: 10:00〜19:00>`
- **やることの記録の置き場所:** `<例: ~/.claude/timetable/todo.md>`（日ごとに `## YYYY-MM-DD` の見出しを立て、その下に件を `- [ ]`（済んでいない）・`- [x]`（済み）で 1 行ずつ書く。ファイルが無ければ、初めての日に作る）

## 流れ

### 1. セッションの名前を変える

- このセッションの名前を `📋M/D 時間割`（今日の日付）にする。名前は `mcp__ccd_session_mgmt__set_session_title`（session_id は `"self"`）で変える。
- やることの記録の、いちばん新しい日付の見出しを「前回の日」とする。記録が無い初めての日は、3 日前を前回の日とする（週末をはさんでも読み落とさないため）。

### 2. 今日やることを集める

- 「読む場所」を、前回の日から今までの分だけ読む。拾う物:
  - 自分宛ての依頼・質問で、まだ返していない物
  - 自分の発言のうち、「やります」「明日返します」など引き受けた件
  - 締切と、時刻の決まった会議
  - 前の日までのセッション（サイドバー）で、途中で止まっている件
  - やることの記録で、済んでいない件
- つながらない場所は止まらずに飛ばし、最後に「読めなかった物」として書く。
- 新しく見つけた件を記録に足す前に、記録全体（済んだ件・やらないと決めた件も）と突き合わせ、同じ件を足し直さない。

### 3. 済んだか分からない件を聞く

- 記録だけでは済んだか分からない件を、AskUserQuestion で 1 問ずつ、3 件まで聞く（4 件目からは翌日に回す）。各問いに、何を見て何が無かったかを 1 行添える。
- 答えごとに記録を直す。

### 4. 時間割を出す

- 見出し: `## M/D(曜) の時間割（HH:MM〜終業の時刻）`。HH:MM は、始業の時刻といまの時刻の遅い方。
- 表: 時刻・やること・この順にした理由。会議も行に入れる。済んだ件は入れない。
- 表の下に 1 行ずつ: 締切が近い物／今日に入らない物／読めなかった物。
- 時間割は、このターンの最後の返事に出す（AskUserQuestion を開いている間は、その前に書いた本文が見えないため）。

### 5. そのまま 1 日、時間割のセッションとして続ける

このセッションは自分では作業せず、順番の相談と、記録と時間割の更新だけをする。

- **時間割の件を引用して「サブで進めて」**（何件かなら「それぞれサブで」）と頼まれたら、件ごとにサブセッションを立てて任せる。頭に `>` を付けて貼られた時間割の行が、その件を指す。
  - 立てる道具は `mcp__ccd_session__start_session`（initiation は `"user_asked"`、context は `"fresh"`）。サイドバーに並ぶセッションとして立てる。サブエージェントで済ませない。
  - 頼み方（prompt）には、件の中身・読む場所・締切・終わったら何を報告してほしいかを書く。
  - 件に合ったフォルダで立てる（リポジトリの件は、そのリポジトリ）。
- サブセッションから報告が来たら、記録を直し、次にやることを 1〜2 行で伝える。立てたサブセッションは `mcp__ccd_session_mgmt__list_sessions`（linked は true）で一覧でき、中身は `mcp__ccd_session_mgmt__list_events` で読める。
- 「時間割を更新」と言われたら、timetable-update の手順で出す。
- 「明日の時間割に入れて」と言われたら、記録の翌日の見出しの下に足す。
- サブセッションの名前の頭の ✅（済み）と ⏸️（ほかの人の答えや日付を待つだけ）は、本人がそのサブセッションで「ダン」「ウェイト」と打って付ける。このセッションでは付けない（答えが来た ⏸️ を外すのは timetable-update）。
- **会話が要約されたら**、作業の前にこの SKILL.md を Read で読み直す（Skill で起動し直さない。1〜4 がもう一度走るため）。
