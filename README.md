# 時間割で回す Claude Code（スキル 4 つ）

Claude のデスクトップアプリの Code タブ（Claude Code）を、「時間割」で回すためのスキルです。
1 日に 10 件以上を同時に進めても、抜けず、迷わず、目の前の 1 件に集中できるようにします。

覚えておくこと（今日やることと順番・誰に何を返すと言ったか・どのセッションで何をしていたか・どれが自分の番か・どこまで済んだか）を、時間割とサイドバーに預けます。

## 打つ言葉

| いつ | どこで | 打つ言葉 | 起きること |
|---|---|---|---|
| 朝に 1 回 | 新しいセッション | 「今日の時間割」 | 今日やることが、時刻と理由つきで並ぶ。このセッションが、その日の「時間割のセッション」になる |
| 1 件ずつ | 時間割のセッション | 時間割の表からその件の行をコピーし、頭に `>` を付けて貼って「サブで進めて」 | その件を、サブセッションが進める |
| 合間に何度でも | 時間割のセッション | 「時間割を更新」 | 済んだ件を確かめて、残りを並べ直す |
| 済んだら | その件のサブセッション | 「ダン」（done） | そのサブセッションの名前の頭に ✅ が付く |
| 人の答えを待つだけになったら | その件のサブセッション | 「ウェイト」 | そのサブセッションの名前の頭に ⏸️ が付く |

サブセッションは、1 つのセッションから立てる別のセッションで、サイドバーで元のセッションの下に入れ子で並びます（アプリの正式な名前ではなく、ここでの呼び名です）。

## 入っているスキル

| スキル | 何をするか |
|---|---|
| [today-timetable](skills/today-timetable/SKILL.md) | そのセッションを今日の時間割のセッションにする。今日やることを集めて時間割を出し、そのまま 1 日、「サブで進めて」と頼まれた件をサブセッションに分けて回す |
| [timetable-update](skills/timetable-update/SKILL.md) | 済んだかを確かめ直してから、時間割を出し直す。待っていた答えが来ていれば ⏸️ を外して知らせる |
| [session-mark-done](skills/session-mark-done/SKILL.md) | セッション名の頭に ✅ を付ける |
| [session-mark-waiting](skills/session-mark-waiting/SKILL.md) | セッション名の頭に ⏸️ を付ける |

session-mark-done は、session-mark-waiting のフォルダにあるスクリプト `mark.py` を使います。この2つは一緒に入れてください。

サブセッションは、サブエージェント（作業の途中で裏で動き、結果だけを返す物）とは別物です。サイドバーに並び、自分で開いて話しかけられます。

## 入れ方

Claude のデスクトップアプリの Code タブで新しいセッションを開き、次を貼ります。

```text
https://github.com/umezy/claude-code-timetable の skills/ にある 4 つのスキル（today-timetable・timetable-update・session-mark-done・session-mark-waiting）を、中のファイルも含めて読み、~/.claude/skills/ に入れてください。
- today-timetable の「自分に合わせる所」（読む場所・始業と終業の時刻・やることの記録の置き場所）は、私に 1 問ずつ聞いて埋める。
- SKILL.md の中のパス（~/.claude/skills/...）は私の環境の絶対パスに、python のコマンド名は私の環境で動く物に書き換える。
- 入れたら、どう打てば動くか（「今日の時間割」など）を最後に教える。
```

入れたら、翌朝から新しいセッションで「今日の時間割」と打って始めます。

## 使う前に

- **デスクトップアプリの Code タブが要ります。** サイドバーもサブセッションも、このアプリの機能です。同じアプリの Chat タブや、CLI（ターミナル）の Claude Code では、このままでは動きません。
- **時間割の材料を読むには、仕事のチャットやカレンダーを Claude Code から読めるようにしておく必要があります**（コネクタや MCP サーバーなど）。つないでいない物は、時間割に入りません。
- **Windows で作り、Windows でだけ確かめています。** `mark.py` は、デスクトップアプリが手元に保存しているセッションの情報から、いまの名前を読みます。見つからないとき（Windows 以外など）は、Claude が get_session で名前を取り直すように 1 行を出します。
- **道具の名前（`mcp__ccd_...`）や保存ファイルの場所は、アプリの版によって変わることがあります。** 動かなくなったら、Claude に「このスキルが動かない。いまのアプリに合わせて直して」と頼んでください。
- **「ダン」「ウェイト」の説明文には、音声入力で化けた同じ音の言葉（団・段・上と など）も並べています。** 要らなければ消してかまいません。
- **スキルは Claude への指示書で、コマンドを実行する物もあります。** 入れる前に、中身に目を通してください。
